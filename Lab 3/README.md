## Lab 3 – Data Preprocessing & Feature Engineering

This lab covers:
- Handling missing values (SimpleImputer)
- Encoding categorical variables (Label Encoding & One-Hot Encoding)
- Feature scaling (StandardScaler & MinMaxScaler)
- Model comparison (KNN vs Decision Tree)
- Pipeline construction
- Feature selection using correlation analysis

Key Findings:
- Scaling significantly affects KNN performance.
- Decision Trees are not sensitive to feature scaling.
- Feature selection can improve performance by reducing dimensionality.
